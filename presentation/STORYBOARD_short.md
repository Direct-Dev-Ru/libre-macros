## Слайд 03 — Killer feature

| | |
|---|---|
| **Заголовок** | Killer feature: готовый конвейер вместо точечного переписывания VBA |
| **Крупный тезис** | libre-macros закрывает **типовой класс** задач, ради которых писали VBA: собрать книги → очистить → свести → оформить — параметрами и визардом, без отдельного макроса на каждый отчёт. |
| **Что закрывает (часть парка VBA)** | • Сбор из папки / многих файлов · • Очистка, дубликаты, замена, столбцы · • ВПР / lookup, сводная, оформление, автофильтр · • Повторяемый сценарий на листе параметров |
| **Честно** | Не 100% всех VBA; кастомную бизнес-логику — пилотом и/или своими шагами Python. Но **массовый «сбор-свести-оформить»** не нужно писать заново с нуля. |
| **Файл** | `s03_pipeline.png` (или `05_pipeline.png`) |
| **Промпт** | Pipeline: VBA-зоопарк → один параметризуемый конвейер libre-macros; иконки «много скриптов» слева, «один конфиг» справа; цвета #0B3D5C / #1A9B8E; 16:9. |
| **Куда** | `assets/s03_pipeline.png` |
