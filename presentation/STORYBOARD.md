# Раскадровка: libre-macros для руководства

**Аудитория:** руководство предприятия (ИТ + бизнес-заказчики отчётов).  
**Цель:** обосновать переход с Microsoft Excel на AlterOffice Calc + пакет макросов **libre-macros** в рамках импортозамещения.  
**Формат:** ~14 слайдов, 12–15 минут + демо по желанию.  
**Выходной файл:** по умолчанию `libre_macros_import_substitution.pptx`  
**ID для скрипта:** `full` · файл: `STORYBOARD.md`

Картинки кладите в `presentation/assets/` с именами из колонки «Файл».  
Если файла нет — слайд всё равно собирается (текст + цветной блок-заглушка).

## Запуск генерации

```bash
cd presentation
pip install -r requirements.txt   # только python-pptx, без бандла в macro-lib

# полная раскадровка (14 слайдов)
python build_pptx.py --storyboard full --out libre_macros_import_substitution.pptx

# краткая (4 слайда) — см. STORYBOARD_short.md
python build_pptx.py --storyboard short --out libre_macros_short.pptx
```

Можно передать путь к файлу раскадровки:

```bash
python build_pptx.py --storyboard STORYBOARD.md --out full.pptx
python build_pptx.py --storyboard STORYBOARD_short.md --out short.pptx
python build_pptx.py --storyboard short --out short.pptx --org "АО «Пример»" --year 2026
```
