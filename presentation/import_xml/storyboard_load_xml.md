# ТЗ и раскадровка: импорт произвольного XML в AlterOffice ACell

**Аудитория:** участники заседания оперативного совета — руководство, ИТ и бизнес-подразделения.  
**Цель:** за 1–2 минуты объяснить разрыв между привычным открытием XML в MS Excel и штатным импортом XML в AlterOffice ACell, а затем показать текущий обходной путь.  
**Формат:** 2 смысловых слайда, без отдельного титульного слайда.  
**Выходной файл:** `import_xml.pptx`  
**ID раскадровки для генератора:** `import_xml` · файл: `storyboard_load_xml.md`

Визуальный стиль: чистая деловая инфографика, формат 16:9, светлый фон, тёмно-синий `#0B3D5C` и бирюзовый `#1A9B8E`; акцентный янтарный цвет — только для обозначения ограничения/статуса. Текст на слайдах — крупный, короткий, без технических подробностей реализации макроса. Схемы на обоих слайдах рисуются редактируемыми векторными элементами PowerPoint генератором; картинки не обязательны.

## Слайд 01 — Проблема: XML в ACell

| Элемент | Содержание |
|---|---|
| **Заголовок** | Простой импорт произвольного XML в ACell затруднён |
| **Подзаголовок** | В MS Excel XML можно открыть как плоскую таблицу. В ACell встроенный импорт требует XML-схему (XSD) и настройки сопоставления XML-структуры с ячейками. |
| **Левая схема — MS Excel** | `XML-файл → открыть / импортировать → плоская таблица` |
| **Правая схема — AlterOffice ACell** | `XML-файл + XSD → настройка соответствия элементов и ячеек → лист` |
| **Вывод / нижняя плашка** | Если готовой схемы нет, а структура XML сложная, подготовка импорта становится отдельной технической задачей. |
| **Файл** | Не требуется: сравнение двух сценариев строится из векторных фигур. |
| **Промпт для необязательной иллюстрации** | Деловая плоская инфографика 16:9 без текста и логотипов: один XML-документ, который слева превращается в аккуратную таблицу, а справа проходит через схему данных и блок настройки сопоставления перед таблицей; тёмно-синий и бирюзовый, янтарный акцент на дополнительном шаге, много свободного пространства. По умолчанию иллюстрация не используется — схему рисует скрипт. |
| **Речь докладчика** | «В Excel типовой XML-файл можно быстро открыть как таблицу. В ACell штатный импорт устроен иначе: для него нужна схема XML, а затем необходимо сопоставить элементы структуры с ячейками. Если схемы у источника нет, это становится дополнительной работой». |
| **Время** | 40–50 секунд |

**Композиция:** заголовок и короткое пояснение сверху; ниже две одинаково оформленные карточки рядом — `MS Excel` и `AlterOffice ACell`. В каждой показать входной XML и результат-таблицу; в карточке ACell явно выделить промежуточный этап `XSD + настройка`. Внизу — один вывод о трудоёмкости отсутствующей схемы. Не создавать впечатление, что ACell вообще не умеет импортировать XML: проблема именно в простом импорте произвольного файла без готовой схемы и настройки.

## Слайд 02 — Обходной путь: Python-макрос

| Элемент | Содержание |
|---|---|
| **Заголовок** | Временное решение: Python-макрос для ACell |
| **Статус** | Обращение к разработчикам ACell через ТНТ направлено; штатная функция пока не реализована. |
| **Схема решения** | `Произвольный XML-файл → Python-макрос → лист электронной таблицы ACell` |
| **Ключевой результат** | Макрос позволяет импортировать произвольные XML-данные на лист ACell как обходной путь до появления штатного решения. |
| **Файл** | Не требуется: последовательность из трёх шагов строится из векторных фигур. |
| **Промпт для необязательной иллюстрации** | Деловая горизонтальная инфографика 16:9 без текста: XML-документ → компактный Python-модуль/шестерёнка → электронная таблица с аккуратными строками; строгая продуктовая подача, тёмно-синий и бирюзовый, никаких логотипов и мелких надписей. По умолчанию иллюстрация не используется — схему рисует скрипт. |
| **Речь докладчика** | «Запрос на штатную возможность уже направлен разработчикам ACell через ТНТ, но пока она не реализована. Чтобы не ждать и не останавливать сценарий, подготовлен Python-макрос: он импортирует произвольные XML-данные непосредственно на лист ACell. Это обходной путь на текущий момент». |
| **Время** | 40–50 секунд |

**Композиция:** в верхней части — неброская статусная плашка об обращении и текущем статусе. В центре — три крупных шага с направленными стрелками: XML-файл, Python-макрос, лист ACell. Внизу — коротко повторить практический результат и временный характер решения.

## Ограничения формулировок

- Не обещать срок реализации штатного импорта: в исходной информации срок не указан.
- Не называть макрос постоянной заменой встроенной функции; это текущий обходной путь.
- Не утверждать, что макрос поддерживает конкретные XML-схемы, уровни вложенности, атрибуты или форматы результата: детали реализации не заданы.
- Не говорить, что ACell совсем не поддерживает импорт XML: встроенный импорт есть, но для него необходимы XSD и настройка сопоставления.

## Сборка

Из корня репозитория:

```bash
.venv/bin/python presentation/build_pptx.py --storyboard import_xml
```

Или явно указать этот файл раскадровки:

```bash
.venv/bin/python presentation/build_pptx.py \
  --storyboard presentation/import_xml/storyboard_load_xml.md \
  --out import_xml.pptx --org "АО «Пример»" --year 2026
```

По умолчанию презентация сохраняется как `presentation/import_xml/import_xml.pptx`. Организацию и год можно задать параметрами `--org` и `--year`.
