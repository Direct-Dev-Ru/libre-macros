# Параметры постобработки (колонка C)

Область: формат параметров в колонке C, `libre_macros_param_codec.py` и исполнители `lm_pp_*`.

## Формат

- **Только JSON** — legacy-текстовая кодировка (`Лист | …`, `->`, `;` между блоками) удалена.
- `param_decode` / `param_encode` в `libre_macros_param_codec.py` работают исключительно с JSON.
- У разных исполнителей (`lm_pp_*`) **свой набор полей** в блоке: градиент — `whole_row`, `sort`; сортировка — `keys`; сетка — `width`, `color`; и т.д.
- Исполнители читают поля из **dict-блока** через `param_decode` + фильтр по листу, без конвертации в текст.

## Тестирование

- **Автотесты не писать и не запускать** — проверка только вручную в LibreOffice Calc.
- Общее правило по проекту: `.kodik/rules/no-tests-by-default.md` (тесты не прогонять,
  если пользователь не попросил явно).
- Каталог `test/` не использовать для новых pytest-скриптов.
- После изменений макросов — переустановка в LO; версию смотреть в журнале (`MACRO_VERSION`).
