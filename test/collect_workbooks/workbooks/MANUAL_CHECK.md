## Сценарии

- **00_all_parameters.xltx** — Справочник параметров сбора (без постобработки).
- **01_merge_one_sheet.xltx** — Сценарий 01: На один лист, JSON-постобработка (сетка, заголовок, зебра).
- **02_merge_many_sheets.xltx** — Сценарий 02: На разные листы.
- **03_columns_filter.xltx** — Сценарий 03: Фильтр столбцов.
- **04_sheets_wildcard.xltx** — Сценарий 04: Шаблоны листов и столбцов.
- **05_all_columns.xltx** — Сценарий 05: Все столбцы.
- **06_sheets_by_index.xltx** — Сценарий 06: Листы по номеру.
- **07_columns_by_index.xltx** — Сценарий 07: Столбцы по номерам.
- **08_columns_by_letters.xltx** — Сценарий 08: Столбцы по буквам.
- **09_fixed_row_count.xltx** — Сценарий 09: Фиксированное число строк.
- **10_product_groups.xltx** — Сценарий 10: Каталог товаров.
- **11_direct_xml_excel_ods.xltx** — Сценарий 11: Прямой перенос через файлы (Способ_переноса=xml_excel_ods), источники .xlsm/.xls/.ods.
- **12_postprocess_json.xltx** — Матрица JSON-постобработки: все основные RANGE/ROW функции.
- **13_merge_sheets_pivot.xltx** — Сценарий 13: На разные листы → объединить_листы_в_один (строка A) → сводная Отдел×Квартал.
- **14_form_to_table.xltx** — Сценарий 14: Копирование анкет (Q/A) → анкета_в_таблицу (by_repeat_key / by_blank_row / шапка листа+блока).
- **15_table_to_form.xltx** — Сценарий 15: Копирование wide → таблица_в_анкету (тело + шапка блока).
- **11_vlookup_1to1_low.xltx** — ВПР 1to1 / low: ~180 строк заказов, ключ [Код_позиции]. Режим «Копирование листов», ВПР между постобработкой диапазона.
- **11_vlookup_1to1_middle.xltx** — ВПР 1to1 / middle: ~850 строк заказов, ключ [Регион,Код_товара]. Режим «Копирование листов», ВПР между постобработкой диапазона.
- **11_vlookup_1to1_high.xltx** — ВПР 1to1 / high: ~3000 строк заказов, ключ [Регион,Код_товара,Склад]. Режим «Копирование листов», ВПР между постобработкой диапазона.
- **11_vlookup_1toN_low.xltx** — ВПР 1toN / low: ~180 строк заказов, ключ [Код_позиции]. Режим «Копирование листов», ВПР между постобработкой диапазона.
- **11_vlookup_1toN_middle.xltx** — ВПР 1toN / middle: ~850 строк заказов, ключ [Регион,Код_товара]. Режим «Копирование листов», ВПР между постобработкой диапазона.
- **11_vlookup_1toN_high.xltx** — ВПР 1toN / high: ~3000 строк заказов, ключ [Регион,Код_товара,Склад]. Режим «Копирование листов», ВПР между постобработкой диапазона.

## ВПР (11_vlookup_*.xltx)

Режим «Копирование листов», источник `sources/vlookup/vlookup_{1to1|1toN}_{low|middle|high}.xlsx`.

| Шаблон | Тип | Объём |
|--------|-----|-------|
| 11_vlookup_1to1_low | 1:1 | ~180 строк, ключ Код_позиции |
| 11_vlookup_1to1_middle | 1:1 | ~850 строк, ключ Регион+Код_товара |
| 11_vlookup_1to1_high | 1:1 | ~3000 строк, ключ 3 поля |
| 11_vlookup_1toN_low | 1:N | дубли справа, low |
| 11_vlookup_1toN_middle | 1:N | дубли справа, middle |
| 11_vlookup_1toN_high | 1:N | дубли справа, high |

Проверить: подтянуты Цена/Валюта/Поставщик, подсветка #FFF2CC, дубли только в 1toN.

## xml_excel_ods (11_direct_xml_excel_ods.xltx)

1. Книга результата сохранена на диск.
2. Direct-фаза может закрыть книгу — нормально.
3. После показа окна — UNO-оформление и Постобработка_Диапазон/Строка (строка состояния).
4. Copy + xml + MERGE_XML_CONVERT_TO_NUMBERS=Да: текстовые числа (1 000 000,00, '1 000 000.00) и даты (с апострофом).
5. Версия в логе ≥ 3.10.79 (отложенная UNO); ≥ 3.10.80 (даты при copy); ≥ 3.10.81 (числа с разрядами при copy).

## 13_merge_sheets_pivot.xltx

На разные листы (`source_pivot.xlsx`) → строка A **`объединить_листы_в_один`** (JSON → `Отчет_Q123`, не ключ B Постобработка_Диапазон) → сводная Отдел×Квартал.
Ожидание: лист `Отчет_Q123`, лист `Сводная_Отдел`; в логе нет ошибок merge_sheets.
