# Источник убрать_объединение

`source_unmerge.xlsx`:

- **Таблица** — шапка 3 строки + пустая + 2 блока (маркер A), плюс гориз. merge D:E
- **Блоки_фиксир** — равномерные блоки по 2 строки (`block_rows`)

Сценарий: `18_unmerge_collapse.xltx`

Ожидание после `header_rows=3`, `marker=A`, `sep=" "` на «Таблица»:
- 1 строка шапки (значения через пробел)
- 2 строки данных без merge
- столбцы D/E на месте
