# Сбор данных о файлах и папках (file_list)

Самодостаточный макрос LibreOffice / AlterOffice Calc: обход каталога, таблица результатов, мини-DLP по именам и путям, колонка Owner на Windows.

---

## Как запустить

1. Откройте книгу `file_list_macro.ods`.
2. Разрешите макросы, если программа спросит.
3. На листе **Старт** нажмите кнопку **«Сбор файлов»**.
4. Заполните диалог и нажмите **«Запуск»**.

Кнопка **«Справка»** на том же листе открывает этот документ (вшит в книгу).

## Диалог: вкладка «Основное»

{{IMAGE: dialog_main | Диалог запуска — вкладка «Основное»}}

- **Путь к папке** — корень обхода; кнопка «Обзор…».
- **Имя листа** — куда писать результат. Пусто = активный лист. Если лист уже есть — спросит: перезаписать / пересоздать / отмена.
- **Глубина** — `1` = только первый уровень внутри папки.
- **Единицы размера** — б / Кб / Мб / Гб.
- **Маски файлов** — например `*.xlsx;*.pdf`. Пусто = все файлы (папки всегда в списке).
- **Сортировка** — дерево, по дате, размеру и другие пресеты.
- **Считать страницы** — PDF / Writer / Impress / Draw через UNO (медленнее).

## Диалог: вкладка «DLP»

Мини-DLP: проверка **имён и полных путей** по словарю регулярных выражений.

{{IMAGE: dialog_dlp | Диалог — вкладка «DLP»}}

- **Анализ наименований** — включить проверку имени, относительного и полного пути.
- **Словарь** — файл **JSON** или **CSV** (UTF-8, разделитель `;` или `,`).
  - CSV: колонка 1 = имя правила, колонка 2 = паттерн или простое слово.
  - Простое слово `конфиденц` превращается в поиск `(?i)конфиденц` (без учёта регистра, подфраза в любом месте).
- **Анализ содержимого** — пока недоступен (поля заблокированы).

При совпадении:

- строка на листе результата **подсвечивается**;
- создаётся лист **`{имя_листа}_DLP`**: колонка «Паттерн», затем копия строки результата;
- если одна строка совпала с несколькими паттернами — в логе **несколько строк**.

Пример словаря: в репозитории `test/file_list/dlp_name_patterns_example.csv`.

## Колонки результата

Типичный набор:

| Колонка | Описание |
|---------|----------|
| Тип | файл / папка |
| Имя | с отступом по глубине |
| Относительный путь | от корня обхода |
| Родитель | родительская папка |
| Глубина | число |
| Размер | в выбранных единицах |
| Страниц | если включён подсчёт |
| Дата изменения | локальное время файла |
| Расширение | у файлов |
| Owner | **только Windows** — владелец NTFS |
| Полный путь | абсолютный путь |

## Owner (Windows)

На Windows макрос добавляет колонку **Owner** (владелец объекта в NTFS).  
На Linux / macOS колонка не создаётся.

---

## Настройки

Параметры диалога сохраняются между запусками:

- Linux: `~/.config/libre-macros/file_list_macro/settings.json`
- Windows: `%APPDATA%\libre-macros\file_list_macro\settings.json`

Рядом при необходимости создаётся словарь имён по умолчанию `dlp_name_patterns.json`.

---

## Советы

- Для больших деревьев начните с малой **глубины** и узких **масок**.
- Подсчёт страниц и обход сети сильно замедляют работу.
- Имена правил в словаре DLP должны быть **уникальными**.
- После обновления standalone-книги пересоберите её скриптом `build_file_list_ods.py`.
