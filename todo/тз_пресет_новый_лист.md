# ТЗ: «Новый лист» при применении пресета

Дополнение к вкладке **Пресеты** визарда параметров (`set_merge_param`).

Связано с: combo `SheetParamCombo` в шапке визарда, `_wp_apply_preset_to_doc`.

---

## 1. Назначение

| Сейчас | Нужно |
|--------|--------|
| Применение пресета на текущий / имена из пресета | То же + цель **новый лист** с именем, запрошенным при применении |
| Combo листов — только существующие | Сверху пункт **«＋ Новый лист…»** |

---

## 2. UI

1. В `SheetParamCombo` (шапка, видна на вкладке Пресеты):  
   `＋ Новый лист…` → затем имена листов параметров книги.
2. Выбор пункта «Новый лист…» (смена combo) **или** «Применить к листу» при выбранном этом пункте → диалог ввода имени.
3. Если имя без префикса параметров — автоматически `префикс_имя`.
4. Лист создаётся (`insertNewByName`), затем пресет пишется на него.

---

## 3. Поведение применения

- **Один блок** пресета (или в мультивыборе отмечен один лист набора) + цель «Новый лист» → строки на созданный лист (имя из пресета не используется).
- **Несколько** листов набора + «Новый лист» → ошибка с просьбой отметить один лист набора (имена из пресета для мульти без «Новый лист» — как раньше).

---

## 4. Приёмка

1. Combo начинается с «＋ Новый лист…».
2. Применить пресет при этом пункте → запрос имени → лист создан → параметры на нём → визард переключается на вкладку Параметр.
3. Выбор «Новый лист…» в combo без Apply тоже создаёт лист и переключает контекст.
4. Мультипресет + Новый лист + все отмечены → понятное сообщение, без порчи книги.
