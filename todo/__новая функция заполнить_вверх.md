# ТЗ: заполнить_вверх (Fill up)

Новая функция постобработки / финальной стадии (RANGE + FINAL; по возможности `Постобработка_xml`).
Визард: блок на выбранный лист или на все листы (`sheet` / `sheets`).

**Имя ключа (fn):** `заполнить_вверх`  
**Синонимы / алиасы:** `fill_up`, `заполнение_вверх`.  
**Lib (план):** `lm_pp_range_fill_up_empty` / `merge_final_fill_up`.  
**Аналог Power Query:** Fill Up / Fill Down (по смыслу).

---

## 1. Цель

Протянуть **значение вверх** по выбранным столбцам:

- найти пустые ячейки в зоне данных;
- заменить пустые значениями ближайшей **следующей** (ниже по листу) непустой ячейки в той же колонке;
- не модифицировать непустые ячейки.

В v1 это работает как “заполнение вверх пустот значением из ближайшей снизу”.

---

## 2. Контракт JSON (v1)

```json
[
  {
    "v": 1,
    "fn": "заполнить_вверх",
    "columns": ["'ФИО'", "'Отдел'"],
    "skip_if_above_not_empty": true,
    "drop_trailing_empty": false
  }
]
```

### 2.1. Поля

- `columns` — `columns_pick`, список заголовков столбцов для заполнения.
- `skip_if_above_not_empty` — если выше-стоящая ячейка уже не пустая, её не трогать (по умолчанию `true`).
  (это соответствует базовому правилу v1 “только пустые”.)
- `drop_trailing_empty` — если ниже в колонке нет непустых значений, пустые сверху так и останутся пустыми (v1: `false`, просто оставить как есть).

---

## 3. Принцип работы

1. Определить `data_range` и `header_row_range` из хоста.
2. Материализовать матрицу значений (`as_values` по умолчанию).
3. Для каждой выбранной колонки:
   - пройти строки снизу вверх;
   - держать “last_seen_value” (последнее встреченное снизу непустое значение);
   - при встрече пустой ячейки — если `last_seen_value` определён, записать его.
4. Записать обновлённую матрицу назад в RANGE/FINAL.
5. Журнал:
   - число заполненных ячеек по каждой колонке.

---

## 4. UX

В визарде:
- `columns` — `columns_pick` с выбором заголовков текущего листа.

---

## 5. Ручная проверка (в Calc)

1. Подготовить колонку с “дырками” пустых значений, где внизу есть заполненная ячейка.
2. Прогнать `заполнить_вверх`.
3. Проверить:
   - значения протянулись только в пустые ячейки;
   - значение из ближайшей снизу непустой использовалось корректно;
   - верхние пустоты без источника остаются пустыми.
