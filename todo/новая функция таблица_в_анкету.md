# ТЗ: таблица_в_анкету

Новая функция постобработки / финальной стадии (RANGE / FINAL; по возможности `Постобработка_xml`).
Визард: блок на выбранный лист (режим «все листы» допустим, если на каждом листе своя wide-таблица).

**Имя ключа (fn):** `таблица_в_анкету`  
**Синонимы / алиасы:** `таблица → анкета`, `wide → форма`, `table_to_form`.  
**Обратная операция:** [новая функция анкета_в_таблицу.md](новая%20функция%20анкета_в_таблицу.md) (`анкета_в_таблицу`).  
**Lib (план):** `lm_pp_range_table_to_form` / `merge_final_table_to_form`.

**Цель:** взять **широкую таблицу** (строка = одна анкета, столбцы = вопросы / поля шапки) и «свернуть» её в **вертикальную анкету**: две колонки «вопрос → ответ», блоки повторяются вниз по листу. Опционально сверху — **шапка листа** (один раз), перед каждым блоком — **шапка экземпляра**.

Round-trip (v1, без потери порядка вопросов при явном `column_order`):  
`анкета_в_таблицу` → правки в wide → `таблица_в_анкету` → снова пары Q/A.

**Не путать** с `развернуть_столбцы` (unpivot): там атрибут/значение — длинная таблица с **несколькими** служебными столбцами и сохранением ключей в каждой строке. Здесь выход — **две колонки** вопрос/ответ и нарезка **блоками** (одна анкета = один вертикальный комплект).

---

## 1. Исходная форма (вход)

Wide-таблица: первая строка — заголовки (вопросы и служебные поля).

| #Блок | Бланк № | Дата       | ФИО    | Возраст | Город  |
|-------|---------|------------|--------|---------|--------|
| 1     | 1001    | 01.02.2026 | Иванов | 30      | Казань |
| 2     | 1002    | 02.02.2026 | Петров | 25      | Уфа    |

Каждая **строка данных** → один блок анкеты.

Общие поля всей формы (кампания, год) могут:

- жить в тех же столбцах и **дублироваться** в каждой строке (как после `анкета_в_таблицу` с шапкой листа) — тогда в выход их пишут **один раз** в шапку листа (`sheet_preamble_columns`);
- либо не быть столбцами wide, а задаваться литералами / `fixed_cells` при записи шапки.

---

## 2. Результат (вертикальная анкета)

### 2.1. Только пары вопрос/ответ (без шапок)

Каждая строка wide → подряд пары; блоки разделены пустой строкой (default) или без разделителя.

| A (вопрос) | B (ответ) |
|------------|-----------|
| ФИО        | Иванов    |
| Возраст    | 30        |
| Город      | Казань    |
| *(пусто)*  |           |
| ФИО        | Петров    |
| …          | …         |

### 2.2. Шапка листа + анкеты ниже

Один раз вверху — служебный блок; затем поток анкет.

| Строка | A / содержимое     | Смысл |
|--------|--------------------|--------|
| 1–4    | Название, период   | **шапка листа** |
| 5      | (пусто, опционально) | разрыв |
| 6+     | ФИО → Иванов …     | блоки анкет |

### 2.3. Повторяющаяся шапка каждого блока

Перед телом каждой анкеты — N строк шапки экземпляра (бланк, дата), затем пары тела.

Совместимо с §2.2: сначала шапка листа, затем блоки «шапка экземпляра + тело».

---

## 3. Принцип работы

1. Определить лист(ы), `data_range` / `header_row_range` (или явные `start_row` / колонки).
2. Прочитать заголовки (первая строка wide) и строки данных.
3. Классифицировать столбцы:
   - **служебные** (`block_index`, `source_start_row`, имена из `skip_columns`) — в пары Q/A **не** писать (если не указано иное);
   - **шапка листа** — `sheet_preamble_columns` (значения брать из **первой** строки данных; при расхождении по строкам — WARN, политика `sheet_preamble_mismatch`);
   - **шапка блока** — `block_preamble_columns`;
   - **тело** — остальные (или явный `body_columns` / `column_order`).
4. Собрать выходную матрицу из двух колонок (`question_column` / `answer_column` на **приёмнике**).
5. Записать по `output` (`new_sheet` / `inplace` / `replace_sheet`).

Порядок внутри блока (default, как у обратной функции `preamble_columns_first`):

1. пары шапки блока (если есть);
2. пары тела.

Шапка листа пишется **до** первого блока, один раз.

## 4. Параметры (JSON)

```json
[{
  "v": 1,
  "fn": "таблица_в_анкету",
  "sheet": "Опрос_таблица",
  "question_column": "A",
  "answer_column": "B",
  "body_columns": ["'ФИО'", "'Возраст'", "'Город'"],
  "block_separator": "blank_row",
  "output": "new_sheet",
  "dest_sheet": "Опрос_анкета"
}]
```

Имена полей шапок и колонок по возможности **совпадают** с `анкета_в_таблицу`, чтобы один и тот же JSON-профиль (с зеркальным `fn`) было проще собирать в визарде.

### 4.1. Лист-источник (wide)

| Поле | Тип | Описание |
|------|-----|----------|
| `sheet` / `sheets` | string / string[] | Лист(ы) wide-таблицы |
| `header_row` | int 1-based | Строка заголовков источника (default: `header_row_range` хоста / 1) |
| `start_row` | int | Первая строка **данных** (default: строка после заголовка) |
| `end_row` | int | Конец данных; пусто — до последней непустой |
| `as_values` | bool | Материализовать формулы (default true) |
| `skip_empty_rows` | bool | Пропускать полностью пустые строки wide (default true) |

### 4.2. Колонки приёмника (анкета)

| Поле | Тип | Описание |
|------|-----|----------|
| `question_column` | col-ref | Куда писать вопросы (default `A`) |
| `answer_column` | col-ref | Куда писать ответы (default `B`; ≠ question) |
| `has_header_in_output` | bool | Первая строка потока анкет — заголовки «Вопрос» / «Ответ» (default false) |
| `question_header` / `answer_header` | string | Подписи при `has_header_in_output` (default «Вопрос», «Ответ») |

### 4.3. Какие столбцы wide куда

| Поле | Тип | Описание |
|------|-----|----------|
| `body_columns` | columns_pick | Вопросы **тела** (порядок пар в блоке). Пусто → все столбцы, кроме skip / preamble |
| `column_order` | string[] | Явный порядок **тела** (алиас/дополнение к `body_columns`) |
| `extra_columns` | string | Столбцы wide вне списков: `append` (в конец тела) \| `drop` (default `drop`) |
| `skip_columns` | columns_pick | Не писать в анкету (напр. `'#Блок'`, `source_start_row`) |
| `skip_block_index` | bool | Если true (default true) — не выводить столбец `block_index` / `#Блок` даже без `skip_columns` |
| `skip_source_row` | bool | То же для колонки стартовой строки источника (default true) |

Нормализация имён столбцов при сопоставлении с `body_columns`: те же флаги, что у обратной fn — `trim_questions`, `collapse_spaces`, `ignore_case` (default как в `анкета_в_таблицу`).

### 4.4. Шапка листа (один раз)

| Поле | Тип | Описание |
|------|-----|----------|
| `sheet_preamble_columns` | columns_pick | Столбцы wide → пары шапки листа (`qa_pair`) |
| `sheet_preamble_mode` | string | `qa_pair` \| `fixed_cells` \| `none` (default `none`; если заданы колонки — `qa_pair`) |
| `sheet_preamble_fields` | list | Для `fixed_cells`: `[{"cell":"B1","as":"Кампания","value_from":"col:'Кампания'"}]` или литерал `"value"` |
| `sheet_preamble_blank_after` | bool | Пустая строка после шапки листа перед анкетами (default true) |
| `sheet_preamble_mismatch` | string | Если значения шапки листа **различаются** по строкам wide: `first` (default, WARN) \| `error` |

Значения `qa_pair` шапки листа: из **первой** непустой строки данных. Не дублировать шапку листа внутри каждого блока.

### 4.5. Шапка блока (перед каждой анкетой)

| Поле | Тип | Описание |
|------|-----|----------|
| `block_preamble_columns` | columns_pick | Столбцы → пары в начале **каждого** блока |
| `block_preamble_mode` | string | `qa_pair` (default при непустом списке) \| `fixed_cells` \| `none` |
| `block_preamble_fields` | list | `fixed_cells`: `cell` относительно **первой строки блока на приёмнике**; значение из столбца wide текущей строки (`value_from`) или литерал |
| `preamble_columns_first` | bool | Шапка блока выше тела (default true). `false` — сначала тело, затем шапка блока (редко) |

Поля из `sheet_preamble_columns` / `block_preamble_columns` **не** повторять в теле, даже если они также попали в `body_columns` (вырезать из тела, WARN).

### 4.6. Разделение блоков

| Поле | Тип | Описание |
|------|-----|----------|
| `block_separator` | string | `blank_row` (default) \| `none` \| `repeat_key` |
| `blank_rows_between` | int | Для `blank_row` — сколько пустых строк между блоками (default 1) |
| `block_start_question` | string | Для `repeat_key`: не вставлять пустую строку; следующий блок начинается с этой формулировки (как вход `by_repeat_key` у обратной fn) |

`repeat_key` + `blank_row` одновременно: приоритет `block_separator`; конфликт → WARN.

Пустые ответы в теле:

| `empty_answer` | Поведение |
|----------------|-----------|
| `write` (default) | Пара с пустым ответом всё равно пишется |
| `skip` | Не писать пару (блок станет короче; обратный `анкета_в_таблицу` с `keep_partial_blocks` это переживёт) |

### 4.7. Вывод

| Поле | Тип | Описание |
|------|-----|----------|
| `output` | string | `new_sheet` (default) \| `inplace` \| `replace_sheet` |
| `dest_sheet` | string | Для `new_sheet` |
| `dest_cell` | string | Угол записи (default `A1`) |
| `clear_source_first` | bool | Перед `inplace` очистить использованный wide-диапазон |
| `forms_start_row` | int | 1-based строка **приёмника**, с которой писать первый блок анкет (после шапки листа). Если не задан: сразу после шапки листа (+ пустая строка) или с `dest_cell` |

`forms_start_row` на **выходе** — зеркало одноимённого поля обратной функции (якорь «здесь начинаются анкеты»).

---

## 5. Валидация

1. `question_column` / `answer_column` не заданы или совпадают → ошибка.
2. 0 строк данных wide → предупреждение; лист не создавать (или только шапка листа — `create_empty`).
3. После классификации 0 пар тела и нет preamble → ошибка.
4. `sheet_preamble_mode=fixed_cells` без `sheet_preamble_fields` → ошибка; то же для блока.
5. `block_separator=repeat_key` без `block_start_question` → ошибка.
6. Столбец из `body_columns` не найден в заголовках → ошибка или WARN + skip (`missing_column`: `error` default).
7. `inplace` с overlap источника и приёмника без `clear_source_first` → ошибка.
8. Слишком длинный выход (напр. > 1e6 пар) → ошибка с порогом в коде.

DEBUG: число строк wide, столбцов тела / шапок, блоков, `block_separator`, dest.

## 6. Примеры сценариев

### 6.1. Классика: wide → пары с пустой строкой между анкетами

Вход как в §6.1 обратного ТЗ (столбцы ФИО, Возраст, Город).

```json
[{
  "v": 1,
  "fn": "таблица_в_анкету",
  "sheet": "Анкеты_wide",
  "question_column": "A",
  "answer_column": "B",
  "skip_columns": ["'#Блок'"],
  "block_separator": "blank_row",
  "output": "new_sheet",
  "dest_sheet": "Анкеты"
}]
```

### 6.2. Без разделителя, старт блока по «ФИО» (удобно для обратного `by_repeat_key`)

```json
[{
  "v": 1,
  "fn": "таблица_в_анкету",
  "sheet": "Анкеты_wide",
  "body_columns": ["'ФИО'", "'Возраст'", "'Город'"],
  "block_separator": "repeat_key",
  "block_start_question": "ФИО",
  "empty_answer": "write",
  "output": "new_sheet",
  "dest_sheet": "Анкеты"
}]
```

### 6.3. Шапка листа из столбцов wide + тело

```json
[{
  "v": 1,
  "fn": "таблица_в_анкету",
  "sheet": "Опрос_wide",
  "sheet_preamble_columns": ["'Кампания'", "'Год'"],
  "sheet_preamble_mode": "qa_pair",
  "sheet_preamble_blank_after": true,
  "body_columns": ["'ФИО'", "'Возраст'", "'Город'"],
  "block_separator": "blank_row",
  "output": "new_sheet",
  "dest_sheet": "Опрос"
}]
```

На приёмнике: сначала пары Кампания/Год (из первой строки), пустая строка, затем блоки тела.

### 6.4. Шапка блока (бланк, дата) + тело

```json
[{
  "v": 1,
  "fn": "таблица_в_анкету",
  "sheet": "Бланки_wide",
  "block_preamble_columns": ["'Бланк №'", "'Дата'"],
  "block_preamble_mode": "qa_pair",
  "body_columns": ["'ФИО'", "'Возраст'", "'Город'"],
  "skip_columns": ["'#Блок'"],
  "block_separator": "none",
  "block_start_question": "Бланк №",
  "output": "new_sheet",
  "dest_sheet": "Бланки"
}]
```

`block_separator: none` + первый вопрос шапки блока как ключ — зеркало входа `block_preamble_rows` + `by_repeat_key` по первой строке шапки (или по «ФИО», если шапка всегда фиксированной высоты и ключ — тело).

### 6.5. Шапка листа (`fixed_cells`) + шапка блока + тело

```json
[{
  "v": 1,
  "fn": "таблица_в_анкету",
  "sheet": "Свод_wide",
  "sheet_preamble_mode": "fixed_cells",
  "sheet_preamble_fields": [
    {"cell": "B1", "as": "Кампания", "value_from": "col:'Кампания'"},
    {"cell": "B2", "as": "Год", "value_from": "col:'Год'"}
  ],
  "forms_start_row": 4,
  "block_preamble_columns": ["'Бланк №'", "'Дата'"],
  "body_columns": ["'ФИО'", "'Возраст'"],
  "block_separator": "blank_row",
  "output": "new_sheet",
  "dest_sheet": "Свод"
}]
```

Для `fixed_cells` шапки листа колонки `as` — подпись в колонке вопросов (или только значение в `cell`, без пары — уточнить в реализации: **рекомендуется** писать метку в `question_column` той же строки, что и `cell` ответа, либо пару в A/B и игнорировать `cell` для qa. **v1:** `fixed_cells` шапки листа пишет в указанные A1 **приёмника**; если `as` задан — в колонке вопросов той же строки, что `cell`.

## 7. Round-trip с `анкета_в_таблицу`

Минимальный обратимый контур v1:

| Туда (`анкета_в_таблицу`) | Обратно (`таблица_в_анкету`) |
|---------------------------|------------------------------|
| `question_column` / `answer_column` | те же на **выходе** |
| `block_mode: by_repeat_key` + `block_start_question` | `block_separator: repeat_key` + тот же вопрос первым в `body_columns` / preamble |
| `block_mode: by_blank_row` | `block_separator: blank_row`, `blank_rows_between` = `blank_rows_to_split` |
| `block_mode: fixed_size` | `block_separator: none`, фиксированный `body_columns` (длина = `questions_per_block`) |
| `sheet_preamble_*` + `forms_start_row` | `sheet_preamble_columns` / `fixed_cells` + `forms_start_row` на приёмнике |
| `block_preamble_*` | `block_preamble_columns` |
| `add_block_index` / `add_source_row` | `skip_block_index` / `skip_source_row` (не восстанавливать служебные колонки в анкету) |

Необратимо без доп. полей: `duplicate_question: concat`, разный порядок вопросов по блокам, `orphan_answer`, объединённые ячейки.

## 8. Место в пайплайне и документация

- Секции: **Постобработка_Диапазон**, **Финальная_обработка**; xml — по возможности.
- Типичный порядок: сбор / wide-обработка (фильтр, ВПР) → **`таблица_в_анкету`** → печать бланков; либо бланки → `анкета_в_таблицу` → ETL → обратно.
- Визард: `body_columns` / preamble — **`columns_pick`**; `block_separator` — combo на русском; блок «Шапка листа» / «Шапка блока» зеркально визарду обратной fn.
- После реализации: те же docs, что у `анкета_в_таблицу`; пресет «туда-обратно» в `param_wizard`.

## 9. Граничные случаи

| Случай | Ожидание |
|--------|----------|
| Одна строка wide | Один блок (+ шапка листа если задана) |
| Пустой ответ в теле | по `empty_answer` |
| Значения шапки листа разные по строкам | `sheet_preamble_mismatch` |
| Столбец только в части строк (пустой заголовок) | skip + WARN |
| `inplace` на том же листе | overlap → ошибка без `clear_source_first` |
| Формулы в ячейках wide | `as_values` |
| Имя столбца с запятой | токены в кавычках, как везде в `columns_pick` |

## 10. Ручная проверка (Calc)

1. Сценарий 6.1 обратного ТЗ → `анкета_в_таблицу` → `таблица_в_анкету` с `blank_row` → сравнить пары (порядок вопросов, ответы).
2. Сценарий с шапкой листа + шапкой блока: общие поля один раз сверху; бланк/дата перед каждым телом.
3. `empty_answer: skip` — короче блоки; повторный `анкета_в_таблицу` даёт пустые ячейки в пропущенных вопросах.
