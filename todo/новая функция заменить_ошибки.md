# ТЗ: заменить_ошибки (Replace errors)

Новая функция постобработки / финальной стадии (RANGE + FINAL; по возможности `Постобработка_xml`).
Визард: блок на выбранный лист или на все листы (`sheet` / `sheets`).

**Имя ключа (fn):** `заменить_ошибки`  
**Синонимы / алиасы:** `replace_errors`, `заменить_ошибки_ячейки`.  
**Lib (план):** `lm_pp_range_replace_errors` / `merge_final_replace_errors`.  
**Аналог Power Query:** заменить значения ошибок на fill/NULL (по смыслу).

---

## 1. Цель

Обнаружить в выбранных столбцах ячейки с ошибками Calc (например `#Н/Д`, `#VALUE!`, `#DIV/0!`, `#NAME?` и т.п.) и заменить их на:

- пусто (`""`),
- литерал/текст,
- или другое значение (v1: текст/пусто).

Для не-ошибочных ячеек значение **не меняется**.

---

## 2. Контракт JSON (v1)

```json
[
  {
    "v": 1,
    "fn": "заменить_ошибки",
    "columns": ["all"],
    "replace_with": "#НЕТ",
    "match": ["#Н/Д", "#ЗНАЧ!"],
    "case_insensitive": true,
    "as_values": true
  }
]
```

### 2.1. Поля

- `columns` — `columns_pick` (или `["all"]` в v1, если допустимо).
- `match` — список строк-лейблов ошибок (по умолчанию “все известные ошибки”):
  - если пустой/отсутствует — заменить любые error-cells;
  - если задан — заменить только совпадающие лейблы.
- `replace_with` — литерал подставки (в v1 текст).
- `case_insensitive` — игнорировать регистр при сравнении лейблов (default true).
- `as_values` — материализовать формулы перед проверкой ошибок (default true).

---

## 3. Принцип работы (ожидаемое поведение)

1. Определить `data_range` и `header_row_range`.
2. Материализовать формулы в значения (`as_values=true`).
3. Для каждой ячейки данных:
   - если значение — error (UNO: error-cell; in-memory fallback: строка вида “#…”) и удовлетворяет фильтру `match`:
     - записать `replace_with` (или "" если пользователь выбрал пусто).
   - иначе: оставить как есть.
4. Журнал: сколько ошибок нашли и сколько заменили по каждому типу (если известны).

---

## 4. UX

- В визарде дать чек “заменять все ошибки” либо поле `match` (опционально).
- Для `match`:
  - в v1 можно оставить ручной ввод через `;` как список лейблов,
  - либо future: combo с предустановленными лейблами.

---

## 5. Ручная проверка (в Calc)

1. В листе создать формулы, которые дают разные ошибки (`#Н/Д`, `#ЗНАЧ!`).
2. Запустить `заменить_ошибки`.
3. Проверить:
   - error-cells заменены только по выбранным колонкам;
   - не-ошибочные ячейки не затронуты.
