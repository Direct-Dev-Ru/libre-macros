# ТЗ: развернуть_столбцы (unpivot)

Новая функция постобработки / финальной стадии (RANGE + FINAL; по возможности `Постобработка_xml`).
Визард: блок на выбранный лист или на все листы (`sheet` / `sheets`).

**Имя ключа (fn):** `развернуть_столбцы`  
**Синонимы / алиасы:** `unpivot`, `развернуть столбцы`, `unpivot_columns`.  
**Lib (план):** `lm_pp_range_unpivot_columns` / `merge_final_unpivot_columns`.
**Аналог Power Query:** Unpivot Columns.

---

## Цель

Преобразовать «широкую» таблицу в «длинную»:

- в исходной таблице есть несколько столбцов (например, месяцы);
- значения этих столбцов превращаются в строки;
- заголовки выбранных столбцов превращаются в значения в отдельной колонке (attribute);
- сами значения — в отдельной колонке (value).

В v1 операция выполняется **in-memory** с использованием матрицы (типовой подход как у прочих RANGE/FINAL шагов).

### Пример «было → стало»

**Было** (широкая таблица: месяцы — отдельные столбцы):

| ФИО | Январь | Февраль | Март |
|-----|--------|---------|------|
| Иванов | 100 | 120 | 90 |
| Петров | 80 | 85 | 95 |

Параметры: `unpivot_columns = ['Январь','Февраль','Март']`, `attribute_column = "Месяц"`, `value_column = "Сумма"`.

**Стало** (длинная: 2 строки × 3 месяца = 6 строк данных):

| ФИО | Месяц | Сумма |
|-----|-------|-------|
| Иванов | Январь | 100 |
| Иванов | Февраль | 120 |
| Иванов | Март | 90 |
| Петров | Январь | 80 |
| Петров | Февраль | 85 |
| Петров | Март | 95 |

- **ФИО** остаётся «как есть» (не в unpivot) — повторяется на каждой выходной строке.
- **Месяц** = бывший заголовок столбца (`attribute`).
- **Сумма** = бывшее значение ячейки (`value`).

Если у Иванова в «Март» пусто и `drop_empty_rows=true` — строка `Иванов | Март | …` **не создаётся**.

## 1. Принцип работы

1. Определить **область данных** (`data_range` + `header_row_range` от хоста).
2. Прочитать данные в память (после materialize формул, как в других PP-шагов; поведение зависит от `as_values`).
3. Имеющиеся **заголовки** на первой строке использовать как исходные имена unpivot-столбцов (attribute).
4. Развернуть:
   - вход: `R` строк данных и `C` unpivot-столбцов;
   - выход: `R * C` строк данных.
5. Выходная таблица:
   - колонки «остального» листа — копируются как есть;
   - добавляются 2 колонки: `attribute_column` и `value_column`;
   - строки создаются по схеме: для каждой исходной строки и каждого unpivot-столбца.
6. Опустошённые значения:
   - в v1 включать строки со значением `empty`/`""` (как в большинстве unpivot).
   - опционально (флаг) можно включить drop-пустых строк — см. §2.

## 2. Контракт JSON (v1)

### 2.1. Поля

```json
[
  {
    "v": 1,
    "fn": "развернуть_столбцы",
    "unpivot_columns": ["'ФИО'", "Месяц*"],
    "exclude_columns": ["'#служебное'"],
    "attribute_column": "Период",
    "value_column": "Значение",
    "output": "inplace",
    "drop_empty_rows": false,
    "skip_header_row": false,
    "dest_sheet": "Unpivot",
    "as_values": true
  }
]
```

**Поля (требования):**

- `unpivot_columns` — **columns_pick**, список заголовков (по умолчанию выбор из заголовков текущего листа).
  - Может быть пустым, если задан `exclude_columns` (режим «развернуть всё, кроме…»).
- `exclude_columns` — **columns_pick**, список заголовков для исключения из unpivot.
- `attribute_column` — литерал имени новой колонки (в заголовке output-таблицы).
- `value_column` — литерал имени новой колонки.
- `output`:
  - `inplace` (по умолчанию) — заменить исходный прямоугольник на развернутую таблицу;
  - `new_sheet` — записать в `dest_sheet` (см. §2.2) начиная с A1.
- `dest_sheet` — имя листа назначения (используется только при `output=new_sheet`).
- `drop_empty_rows` — если `true`, не создавать строку, если `value_column` пустой/пустая строка.
- `skip_header_row` — для unpivot не рекомендуется (v1: запрещено/или игнорируется).
- `as_values` — материализовать формулы в значениях перед unpivot.

### 2.2. Отладка и журнал

В журнале (лог шагов):

- исходный размер (`R x C`) и итоговый размер (`R*C`);
- число строк, которые были отброшены при `drop_empty_rows=true`.

## 3. Реализация (ожидаемое поведение)

1. Определить набор unpivot-столбцов:
   - если задан `unpivot_columns` — взять их;
   - иначе взять «все колонки data_range» минус `exclude_columns`.
2. Для каждого исходного `ri` и каждого unpivot-столбца `ci`:
   - attribute = заголовок `ci`;
   - value = исходная ячейка `ri, ci`.
3. Записать результат:
   - `inplace`: очистить исходный прямоугольник и записать новую матрицу по левому верхнему углу источника;
   - `new_sheet`: создать/выбрать `dest_sheet` и записать с A1.

---

## 4. UX в визарде

Поля:

- `unpivot_columns` — `columns_pick` + `choices_from_headers=True`;
- `exclude_columns` — `columns_pick` (опционально, показать только если пользователь хочет «кроме…»);
- `attribute_column`, `value_column` — обычные edit (литералы).

Подсказка на русском:

- «Unpivot: каждый выбранный столбец превращается в блок строк; имя столбца становится значением колонки “attribute”.»

## 5. Примеры JSON (+ таблицы)

### 5.1. Развернуть конкретные месяцы

```json
[{
  "v": 1,
  "fn": "развернуть_столбцы",
  "unpivot_columns": ["'Январь'", "'Февраль'", "'Март'"],
  "attribute_column": "Месяц",
  "value_column": "Сумма",
  "output": "inplace",
  "drop_empty_rows": true,
  "as_values": true
}]
```

**Было:**

| ФИО | Отдел | Январь | Февраль | Март |
|-----|-------|--------|---------|------|
| Сидоров | IT | 10 | | 30 |

**Стало** (`drop_empty_rows=true` — пустой Февраль отброшен):

| ФИО | Отдел | Месяц | Сумма |
|-----|-------|-------|-------|
| Сидоров | IT | Январь | 10 |
| Сидоров | IT | Март | 30 |

### 5.2. Развернуть «все кроме» ключа

```json
[{
  "v": 1,
  "fn": "развернуть_столбцы",
  "unpivot_columns": [],
  "exclude_columns": ["'Код_позиции'", "'ФИО'"],
  "attribute_column": "Месяц",
  "value_column": "Значение",
  "output": "new_sheet",
  "dest_sheet": "Unpivot"
}]
```

**Было** (разворачиваются все столбцы, кроме `Код_позиции` и `ФИО`):

| Код_позиции | ФИО | Январь | Февраль |
|-------------|-----|--------|---------|
| P01 | Орлов | 5 | 7 |

**Стало** (на лист `Unpivot`):

| Код_позиции | ФИО | Месяц | Значение |
|-------------|-----|-------|----------|
| P01 | Орлов | Январь | 5 |
| P01 | Орлов | Февраль | 7 |

## 6. Ручная проверка (в Calc)

1. Подготовить 1 лист с 1 ключевой колонкой и 3-5 «месяцами» как отдельными столбцами.
2. Запустить сценарий: `развернуть_столбцы`.
3. Проверить:
   - число строк стало `R * C`;
   - attribute_column содержит заголовок каждого исходного столбца;
   - value_column содержит исходные значения;
   - заголовок исходной шапки не попал в данные (кроме attribute/value заголовков output-таблицы).
