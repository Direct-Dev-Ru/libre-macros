# Иллюстрации для `02_INSTALL_USER.md`

Разместите скриншоты с именами `fi1.png` … `fi11.png` в этой папке.

В документе рисунки в **гибридном** формате: подпись со ссылкой + `![](figs/02_INSTALL_USER/fiN.png)` ниже.

После съёмки при необходимости пересохраните PNG в RGB (без альфа-канала gnome-screenshot) — так надёжнее открывается во встроенном просмотрщике.

|------|-----------|
| `fi1.png` | **Сервис → Параметры → Безопасность → Безопасность макросов** — уровень, допускающий выполнение макросов из документа |
| `fi2.png` | **Сервис → Макросы → Выполнить макрос…** — дерево с тестовым Python-макросом (HelloWorld или аналог) |
| `fi3.png` | Открытый `MacroInstaller_bundled.ods`: ячейки **A2** (`_Встроенный_Пакет_`) и **B2** (версия) |
| `fi4.png` | Лист установщика: кнопка **«Запуск диалога установки»** |
| `fi5.png` | **Выполнить макрос…** — путь **этот документ → Python → installer_bundled → install_macros** |
| `fi6.png` | Диалог предупреждения безопасности при запуске установщика — кнопка **Разрешить** |
| `fi7.png` | Окно **«Выберите макросы (встроенный архив)»** со списком и кнопкой **«Установить выбранные»** |
