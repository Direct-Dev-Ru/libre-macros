# Макрос `param_wizard` — визард параметров

**Файл:** `macro-lib/param_wizard.py`  
**Точка входа:** `set_merge_param`  
**Установка:** `./macro-lib/install.sh param_wizard` (см. [03_INSTALL_DEV.md](03_INSTALL_DEV.md))

Визард упрощает заполнение листа **`Параметры_Объединения*`** для макроса [collect_workbooks](04_DATA_COLLECTION.md): выбор параметра, подсказки, ввод значения, запись в нужную строку/столбец. На отдельной вкладке — **пресеты** (сохранённые наборы параметров).

Диалог подтверждения перед сбором (`collect_workbooks`, режим «Диалог») показывает только **сводку параметров** и кнопки «Запуск» / «Отмена». Пресеты настраиваются **только в этом визарде**.

---

## 1. Когда использовать

| Задача | Визард | Альтернатива |
|--------|--------|--------------|
| Задать «Режим», «Начало_Строка», фильтры | ✅ | Ввод вручную в B |
| Добавить шаг постобработки (B/C) | ✅ | Строки «Постобработка_Диапазон» / «Постобработка_Строка» |
| Добавить шаг **Постобработка_xml** (direct) | ✅ | Строка «Постобработка_xml» (только при `xml_excel_ods`) |
| Настроить **ВПР** (JSON: диапазоны, join) | ✅ | Строка «ВПР» на листе параметров |
| **Копировать строку(и) параметров** | ✅ | Меню / toolbar / context; `copy_param_rows` |
| **объединить_листы_в_один** / **разделить_листы** | ✅ | Отдельная строка A, JSON в C (не Постобработка_Диапазон) |
| **Строка_Заголовков** (многоэтажная шапка) | ✅ | B=`смотри в C`, JSON `строка_заголовков` в C |
| **разделить_по_столбцам** / **условный_столбец** / **столбец_по_лямбде** / **добавить_столбец** | ✅ | Постобработка_Диапазон / Финальная_обработка |
| **Листы_удалить**, **Добавить_в_карту_переменных**, **Ручной_ввод_в_карту_переменных** | ✅ | Фильтры и карта переменных (+ ручной ввод) |
| Правило «Ячейка_В_Столбец» | ✅ | Повтор имени в A, значение в B |
| «удаление_верхних_строк» (до постобработки) | ✅ | B: `Лист -> N` / `= N` / `\ N` |
| Сохранить / применить набор параметров (пресет) | ✅ вкладка «Пресеты» | Ручное копирование листа |
| Путь к файлу-источнику | ✅ вкладка «Параметр», «Файлы-Источники» | [08_PICK_SOURCE.md](08_PICK_SOURCE.md) — выбор по ячейке |
| Запуск сбора | ❌ | `collect_workbooks` |

## 2. Запуск

1. Откройте книгу с листом `Параметры_Объединения` (или активируйте его при нескольких листах группы).
2. **Инструменты → Макросы → Выполнить макрос… → Python → param_wizard → set_merge_param**

Рекомендуется назначить макрос на кнопку формы на листе параметров.

---

## 3. Окно визарда — вкладка «Параметр»

Компактная раскладка: поле **значения на всю ширину**, кнопки файлового режима — **отдельной строкой ниже**.

| Элемент | Назначение |
|---------|------------|
| **Параметр** | Выпадающий список всех имён из колонки A (каталог синхронизирован с `collect_workbooks`) |
| **Значение** | Текст, число, пути, файл или **список** (для параметров с фиксированными вариантами) |
| **Обзор…** | FilePicker — только для «Файлы-Источники» (см. §6) |
| **Очистить последний / Очистить все** | Только для «Файлы-Источники» — убрать последний путь или все пути из поля значения |
| **Доп. аргументы (C)** | Rest для постобработки (аргументы функции в колонке C) |
| **Описание** | Подсказка, каталог значений B, примеры C, текущие значения на листе |

**OK** — записать выбранный параметр на лист. **Отмена** — закрыть без записи.

При первом запуске на пустой книге визард **создаёт лист** «Параметры_Объединения»:
если есть сохранённые пресеты — диалог выбора и загрузка; иначе — шаблон xml+ВПР
(`vlookup_data_low_old.xlsx`, `Постобработка_xml`, ВПР).

## 4. Окно визарда — вкладка «Пресеты»

Пресеты — это снимки листа «Параметры_Объединения» в JSON-файле:

`~/.config/libre-macros/collect_workbooks/merge_param_presets.json`  
(Windows: `%APPDATA%\libre-macros\collect_workbooks\`)

| Элемент | Назначение |
|---------|------------|
| **Пресет** | Список сохранённых наборов |
| **Имя для сохранения** | Имя нового пресета или переименование при сохранении; синхронизируется с выбором в списке |
| **Комментарий пресета** | Только чтение: строка «Комментарий» из пресета |
| **Что делает этот пресет** | Только чтение: краткая сводка (режим, источники, листы, постобработка…) |
| **Сохранить** | Записать текущий лист в JSON; при совпадении имени — вопрос о перезаписи |
| **Удалить** | Удалить выбранный пресет (с подтверждением) |
| **Экспорт / Импорт** | Один пресет в отдельный `.json` файл |
| **Применить к листу** | Заменить содержимое «Параметры_Объединения» выбранным пресетом |
| **Очистить все** | Удалить файл пресетов целиком (с подтверждением) |

### Первый запуск и примеры

При переходе на вкладку «Пресеты», если файла нет или он пуст, автоматически создаётся JSON с **18 примерами** `Я01…Я18`:

| № | Сценарий | xml_excel_ods | UNO |
|--|--|--|--|
| 1 | На один лист | Я01 | Я10 |
| 2 | На разные листы | Я02 | Я11 |
| 3 | Копирование листов | Я03 | Я12 |
| 4 | ВПР | Я04 | Я13 |
| 5 | Сводная | Я05 | Я14 |
| 6 | Структура данных | Я06 | Я15 |
| 7 | Визуал | Я07 | Я16 |
| 8 | ВПР legacy | Я08 | Я17 |
| 9 | Смешанные форматы | Я09 | Я18 |

**Я05 / Я14:** `На разные листы` (`source_pivot`) → строка A **`объединить_листы_в_один`** (JSON → `Отчет_Q123`) → сводная `Отдел×Квартал`. Не ключ B Диапазон.

Пути к источникам — абсолютные: `$HOME/Documents/alter_office_macros/test/collect_workbooks/sources/…` (Linux) или `S:\My Documents\alter_office_macros\…` (Windows после установки из bundled `.ods`). После **«Очистить все»** при следующем открытии вкладки примеры создаются снова. Чтобы обновить встроенные примеры после смены логики пресетов — **«Очистить все»** или удалить `~/.config/libre-macros/collect_workbooks/merge_param_presets.json`.

На вкладке «Пресеты» кнопка **OK** **недоступна** — для записи параметра перейдите на вкладку «Параметр»; для пресета используйте **Сохранить** или **Применить к листу**.

## 5. Предзаполнение по текущей ячейке

Если при запуске курсор стоит в **строке с известным параметром** (имя в колонке A):

- в списке «Параметр» выбирается этот параметр;
- в форму подставляются значения с учётом **активного столбца**;
- для **Файлы-Источники** — непустые пути из столбцов B… **до активного столбца включительно**, склеенные через `;` (если курсор в C, а в B уже есть путь — он попадёт в поле, даже если C пуст);
- для постобработки — B и при необходимости C (если курсор в C);
- для **ВПР** — сразу открывается поддиалог B–F (см. §6), без главного окна визарда.
- для **объединить_листы_в_один** / **разделить_листы** — сразу поддиалог JSON (как у ВПР).

После **OK** для «Файлы-Источники» пути **всегда перезаписывают всю строку** (B, C, D…) из одного поля; для остальных параметров запись идёт в **ту же строку** (и столбец, если курсор был в B/C/D…), а не в новую ячейку.

Если курсор на пустой строке или вне таблицы параметров — открывается первый параметр каталога без предзаполнения.

## 6. Режимы ввода по параметрам

| Режим | Параметры (примеры) | Поле значения | C |
|-------|---------------------|---------------|---|
| `text` | Листы, Столбцы, Комментарий | текст | — |
| `number` | Начало_Строка, Число_Строк, расширенные | целое число | — |
| `choice` | Режим | **выпадающий список** | способ переноса (инлайн) |
| `choice` | Источник_в_первой_колонке, Дата_… | **выпадающий список** | — |
| `choice` | **Способ_переноса** (отдельная строка, совместимость) | выпадающий список | — |
| `files` | Файлы-Источники | см. ниже | — |
| `postprocess_range` | Постобработка_Диапазон | **список функций** | rest |
| `postprocess_row` | Постобработка_Строка | **список функций** | rest |
| `cell_to_column` | Ячейка_В_Столбец | `A:1 -> ИмяСтолбца` | — |
| `text` | удаление_верхних_строк | `1_Заказы -> 5` или `= 4` или `\ 2` | — |
| `vlookup` | **ВПР** | поддиалог B–F (см. §6) | — |
| `merge_sheets` | **объединить_листы_в_один** | диалог JSON (sheets, dest_sheet, …) | **C = JSON** |
| `split_sheets` | **разделить_листы** | диалог / JSON (`run_phase`, source, split_*) | **C = JSON** |
| `header_row` | **Строка_Заголовков** | B=`смотри в C`; субдиалог «Многоэтажный заголовок» | **C = JSON** |
| `add_to_variables_map` | **Добавить_в_карту_переменных** | маски file/sheet, cell, name | **C = JSON** |
| `manual_variable_input` | **Ручной_ввод_в_карту_переменных** | name, value_kind, data_type, choices, prompt… | **C = JSON** |
| `sheet_filter` | **Листы_удалить** / **Листы_не_удалять** | шаблоны в B; опционально `filter` в C | **C = JSON** |

### «Режим» и способ переноса (колонка C)

| Ситуация | Поведение |
|----------|-----------|
| В списке «Параметр» выбран **Режим** | Под значением режима появляется второй список **Способ переноса**; текущее значение читается из **колонки C** строки «Режим» (если пусто — `По_API`) |
| **OK** при редактировании «Режим» | Записываются B (режим) и **C** (способ переноса) в **одной** строке |
| Режим **Копирование листов** | В списке «Режим» поле «Способ переноса» **скрыто** (inline C не редактируется). Для **`xml_excel_ods`** — отдельная строка **`Способ_переноса`** в колонке A или пресет визарда (значение попадает в C/B) |
| Отдельная строка **Способ_переноса** | Редактируется как обычный параметр-выбор; при сборе **имеет приоритет** над C в «Режим»; работает и для «Копирование листов» |

### Режим `vlookup` (**ВПР**)

Основной путь — **JSON в колонке C**. Поддиалог задаёт смысловые поля (не «ячейки B–F»):

| Поле UI | JSON | Смысл |
|---------|------|--------|
| Лист + **Лев.диапазон** / **Прав.диапазон** | `left` / `right`: `sheet`, `range` | Пустой `range` — used-area; явный A1 (`C2:F40`, `1:200`, `D:H`) — заголовок = первая строка диапазона; при сохранении пишутся derived `start_row` / `start_col` / `header_row` |
| **Тип соединения** | `join_type`: `left` \| `inner` \| `full` | Левое — как раньше; внутреннее — только совпадения (строки без ключа справа удаляются); полное — два прохода ВПР + строки только справа на левом листе |
| **Колонки в Лев. из Прав. (←)** | `extract_columns` | Столбцы с правой таблицы |
| **Колонки в Прав. из Лев. (→)** | `extract_columns_right` | Только при `full` |
| **Обработка множ.совпадений** | `multi_match`: `all` \| `first` \| `last` | Несколько строк справа по ключу: все (как раньше), только первая или только последняя |
| **Итоговые параметры** | цвет, `not_found_fill`, дубли, мульти, суффикс `_R`, … | Подсветка новых колонок; значение для «не найдено» (`_ПУСТО_` → пустая ячейка) |

| Ситуация | Поведение |
|----------|-----------|
| Курсор на **существующей** строке «ВПР» | Сразу открывается **поддиалог ВПР** (без главного окна визарда) |
| **Новая** строка ВПР (выбор «ВПР» в списке параметров) | Главное окно → **OK** → поддиалог ВПР |

Шапка листа параметров при JSON-ВПР оформляется только для B–C («Значение 1/2»), без ложной раскраски D–E.

Legacy B–F ещё читается исполнителем; **новые** возможности (`range`, `full`, `inner`, `multi_match`) — только через JSON.

### Копирование строк параметров

Макрос **`copy_param_rows`** (меню / toolbar / контекстное меню ячейки): копирует выделенные строки листа параметров **ниже** выделения.

- Уникальные параметры (`multi_row=False`, напр. «Режим») — копирование **запрещено** (отмена всего выделения).
- Повторяемые (ПП, ВПР, …) — можно дублировать.
- Если снизу уже есть ≥ N пустых строк — запись без `insertRows`; иначе вставка N строк со сдвигом (не затирает существующие).
- Дискретный мультиселект поддерживается (строки по возрастанию → один блок вставки). Лимит: 100 строк.

Поддиалог ВПР (кратко по опциям):

| Опция | Значение |
|-------|----------|
| Цвет для новых колонок | hex / пресет; пусто / «Нет» — без подсветки |
| Значение для не найдено | по умолчанию **#Н/Д**; **`_ПУСТО_`** / **`_EMPTY_`** — пустая ячейка |
| Обработка множ.совпадений | **Все** (по умолчанию) / **первый** / **последний** |
| Дубли | при `all`: заполнять все совпадающие строки или только первую |
| Мульти | все совпадения в одну ячейку через перевод строки |
| СЖ_ПРОБЕЛЫ | trim ключей перед сравнением |
| Суффикс _R | суффикс к именам новых колонок с правой (по умолчанию вкл.) |

Полное описание всех полей и пример JSON — кнопка **«Справка»** в поддиалоге (и `docs/13_JSON_PARAMS.md`).

### Режим `files` («Файлы-Источники»)

- в поле значения — **все пути одной строкой**, разделитель `;` или `,`;
- при открытии визарда пути из столбцов B… **до активной ячейки** склеиваются в это поле (см. §5);
- **Обзор…**: пустое поле → домашняя папка, путь **добавляется**; если пути уже есть → стартовая папка из **последнего** пути, новый файл **дописывается**;
- **Очистить последний** / **Очистить все** — правка списка в поле без записи на лист;
- **OK** — строка **разбивается**, пути в B, C, D…; для новых столбцов — оформление и заголовок «Значение N»; **объединение ячейки «Комментарий»** пересчитывается на все столбцы значений (как в `pick_source_file`).
- В пути/маске допускается `<<Переменные.Имя>>` (подстановка из runtime-карты **до** разворота glob). Для ручного ввода строка `Ручной_ввод_в_карту_переменных` должна быть **выше** «Файлы-Источники».

### Кнопка «Справка»

Во **всех** визардах и подвизардах параметров (включая «Доп_Параметры_Источника», sheet-block формы, сортировку, ВПР, сводную, оркестратор `collect_pack`, главный визард) справа в футере есть **«Справка»** — модальное окно с описанием полей (не закрывает родительский диалог). Текст берётся из подсказок визарда / схемы формы / REST-hints функции.

### Валидация

- **choice** и **postprocess_*** — значение B должно быть из выпадающего списка.
- **number** — целое число.
- **postprocess_*** — B обязательно; для C см. описание выбранной функции в поле «Описание».

Списки функций постобработки берутся из `collect_workbooks.py` (карты `MERGE_RESULT_POSTPROCESS_*_MAP`). Если макрос сбора не установлен рядом — используются встроенные fallback-списки визарда.

## 7. Повторяемые параметры (несколько строк с одним именем в A)

| Параметр | Поведение по OK |
|----------|-----------------|
| Постобработка_Диапазон | Новая строка внизу таблицы: A=имя, B=функция, C=rest |
| Постобработка_Строка | То же |
| Ячейка_В_Столбец | То же (B,C,D… — по файлам) |

При открытии визарда **из существующей** строки постобработки значения B/C показываются в форме; OK обновляет эту строку.

---

## 8. Параметры с несколькими столбцами (B, C, D…)

**Файлы-Источники**:

- B, C, D… — по одному пути на файл;
- визард редактирует все пути **в одном поле** и по **OK** раскладывает по столбцам (см. §6);
- для выбора файла **в конкретную ячейку** без визарда — **pick_source_file**.

---

## 9. Зависимости

- **LibreOffice** с Python-UNO.
- Для полного каталога постобработки и имён констант — установленный **`collect_workbooks.py`** в том же каталоге `Scripts/python` (визард добавляет `macro-lib` в `sys.path` при импорте).

Без `collect_workbooks` визард работает с встроенными списками и подсказками, но расширенные параметры производительности могут отсутствовать в каталоге.

Пресеты (вкладка «Пресеты») встроены в `param_wizard.py`; файл `merge_param_presets.json` создаётся и обновляется визардом автоматически.

## 10. Примеры

### Режим сбора

1. Запуск на листе параметров.
2. Параметр: **Режим** → B: **На один лист** (из списка).
3. OK.

### Шаг постобработки

1. Параметр: **Постобработка_Диапазон**.
2. B: **тонкая_сетка**, C: пусто.
3. OK — новая строка в таблице.

### Пресет

1. Настройте лист параметров.
2. Вкладка **Пресеты** → имя → **Сохранить**.
3. Позже: выберите пресет → **Применить к листу** → запустите `collect_workbooks`.

### Несколько файлов через визард

1. Параметр **Файлы-Источники**.
2. **Обзор…** — выберите первый файл (путь появится в поле).
3. Снова **Обзор…** — добавьте второй файл (или вставьте пути через `;`).
4. OK — пути в B, C, …

### Расширенный параметр `MERGE_FONT_SIZE`

В каталоге визарда есть строка **`MERGE_FONT_SIZE`** (расширенный параметр `collect_workbooks`): целое число в B — размер шрифта (pt) заголовка и данных на листе результата. По умолчанию в коде **11**; см. [04_DATA_COLLECTION.md](04_DATA_COLLECTION.md) §6.2.

### Редактирование существующего

1. Установите курсор в ячейку B строки «Пропуск_строк_источника».
2. Запустите визард — в форме появится текущее значение.
3. Измените и нажмите OK — обновится та же ячейка.

### Редактирование существующего ВПР

1. Установите курсор в любую ячейку строки «ВПР» (B…F).
2. Запустите визард — **сразу** откроется форма параметров ВПР.
3. Измените поля и нажмите OK — строка B–F обновится.

### Новый шаг ВПР

1. Запустите визард на листе параметров.
2. Выберите **ВПР** в списке «Параметр».
3. Нажмите **OK** в главном окне → откроется поддиалог ВПР.
4. Заполните B–F и нажмите OK — добавится новая строка.

### Sheet-block: `копирование_диапазонов`

Форма открывается из шага **Постобработка_Диапазон** / **Финальная_обработка**, когда в B выбран ключ `копирование_диапазонов` (или алиас) и нажато **Параметры…** / OK с формой блока.

| Поле формы | JSON | Примечание |
|------------|------|------------|
| Лист-источник | `source_sheet` | combo по листам книги |
| Диапазон A1 | `source_range` | `A1:D10`, `B:B`, `2:5` |
| Строки (альт.) | `source_rows` | если range пуст |
| Столбцы (альт.) | `source_columns` | `columns_pick` по заголовкам источника |
| Листы-приёмники | `dest_sheets` | имена через `,` / `;` |
| Якорь A1 | `dest_cell` | default `A1` |
| Режим | `mode` | «Замена» / «Вставка» |
| Ось сдвига | `insert_axis` | «Авто» / «Строки» / «Столбцы» |
| Содержимое | `content` | «Значения» / «Формулы» |
| С оформлением | `with_formatting` | bool |
| Очистить источник | `clear_source` | bool |
| Создать лист, если нет | `create_missing_dest` | bool |
| Вовлечь в следующие шаги | `involve_dest` | default Да |
| Строка заголовков | `header_row` | 1-based на приёмнике |

Пример после OK в колонке C:

```json
[{"v":1,"fn":"копирование_диапазонов","source_sheet":"Сводная","source_range":"A1:D20","dest_sheet":"Отчет","dest_cell":"B3","mode":"replace","content":"values"}]
```

Схема JSON и расширенные примеры — [13_JSON_PARAMS.md](13_JSON_PARAMS.md); поведение replace/insert — [05_POSTPROCESS.md](05_POSTPROCESS.md).

### Мульти-совпадение в одну ячейку

1. В поддиалоге ВПР включите **Мульти**.
2. При нескольких строках справа с одним ключом значения каждого подтягиваемого столбца пишутся **в одну ячейку**, через перенос строки.
3. Пустое значение в одной из строк совпадения даёт пустую строку внутри ячейки (два переноса подряд).

### Заполнитель «не найдено» — пустая ячейка

В поле **«Значение для не найдено»** поддиалога ВПР укажите **`_ПУСТО_`** (или **`_EMPTY_`**). При сборе для строк без совпадения в извлечённых колонках будет **пустая ячейка**, а не `#N/A`.
