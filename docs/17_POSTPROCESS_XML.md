# Постобработка_xml — сводка реализации

Актуально на **3.10.523** (режим `Способ_переноса = xml_excel_ods`).

| Что | Где |
|-----|-----|
| Параметр листа | **Постобработка_xml** (колонка A) |
| Карта ключей | `_PP_XML_MAP_SPEC` → `MERGE_RESULT_POSTPROCESS_XML_MAP` (`collect_workbooks.py`) |
| Исполнение в файле | `libre_macros_direct_lib.direct_run_xml_postprocess` |
| UNO после показа книги | `_merge_run_xml_excel_ods_uno_phase` (отложенная фаза) |
| UNO-добивка xml | `_merge_apply_xml_uno_pending` / очередь freeze / очередь новых листов |
| Текст → число/дата (copy) | `direct_apply_copy_sheets_convert_datetimes`, `_direct_try_parse_number_text` |

Параметры постобработки — **только JSON** (`libre_macros_param_codec.py`).

## Пайплайн xml_excel_ods (полный)

Поддерживаемые режимы сбора: **На один лист**, **На разные листы**, **Копирование листов**.

### Фаза A — direct (файл на диске, книга закрыта)

```
сохранить книгу результата (.uno:Save)
  → закрыть документ
  → [COPY] UNO merge_on_copy_sheets уже выполнен до save/close
  → [ONE/MANY] direct_merge_on_* — чтение источников, запись в .ods/.xlsx
  → [COPY] автообрезка листов (Строка_Заголовков / Начало_Строка) или явное удаление_верхних_строк
  → [COPY] распознавание текстовых чисел и дат (MERGE_XML_CONVERT_TO_NUMBERS=Да)
  → удаление_верхних_строк (явное, в файле)
  → Постобработка_xml + отдельные A-строки ВПР / объединить_листы_в_один / разделить_листы (в файле / очередь UNO)
  → reopen книги (Hidden)
  → постановка отложенной UNO-задачи (_MERGE_XML_DEFERRED_UNO_JOB)
```

Прогресс фазы A: диалог (при `Отображение_прогресса` = **Диалог**) на **временной книге-якоре**, пока целевая книга закрыта.

### Фаза B — UNO (после показа книги пользователю)

```
закрытие диалога прогресса
  → показ окна книги результата (_merge_ui_anchor_end)
  → _merge_run_xml_excel_ods_uno_phase:
       as_values (если нужно)
       → встроенное оформление
       → Постобработка_Диапазон / ВПР / объединить_листы_в_один / Постобработка_Строка (UNO)
       → добивка на листах, созданных в xml
       → Финальная_обработка
       → Постобработка_xml+UNO (autofit, автофильтр, …)
       → закрепить_заголовок (freeze после видимого окна)
  → статус — только строка состояния Calc
  → лог — консоль и лист «Сбор_книг_лог»
  → итоговое сообщение (MessageBox)
```

**Важно:** `Постобработка_Диапазон` и `Постобработка_Строка` при xml_excel_ods выполняются в **фазе B**, а не на скрытой книге. Это нужно для freeze, корректного UNO-merge и шагов, зависящих от видимого окна.

### Сосуществование xml + обычной постобработки

| Параметр | Где выполняется |
|----------|-----------------|
| `Постобработка_xml` | Фаза A (файл) + часть шагов UNO-пилот в фазе B |
| `ВПР` / `ВПР_XML` | ВПР в файле; UNO-ВПР в pipeline **пропускается** (уже в файле) |
| `Постобработка_Диапазон` / `Постобработка_Строка` | Фаза B (UNO), **не отключаются** при наличии xml |
| `Финальная_обработка` | Фаза B (UNO) |

## MERGE_XML_CONVERT_TO_NUMBERS: числа и даты

Флаги на листе параметров (строки `MERGE_XML_CONVERT_TO_NUMBERS`, `MERGE_XML_DATETIME_FORMATS`).

| Режим сбора | Поведение |
|-------------|-----------|
| На один / разные листы | При чтении каждой ячейки источника: `_direct_coerce_cell_value` → `_coerce_text_value` (числа, в т.ч. `1 000 000,00`, + даты по форматам) |
| **Копирование листов** | UNO копирует листы как есть; затем **отдельный проход по файлу** `direct_apply_copy_sheets_convert_datetimes` |

### Распознавание дат и чисел при копировании листов

1. Снимается ведущий апостроф (`'02.02.1976`, `'1 000 000,00`).
2. **Даты** — только по **MERGE_XML_DATETIME_FORMATS** или базовому набору.
3. **Числа** — пробел или апостроф между разрядами (`1 000 000,00`, `1'000'000.00`); дробная часть через `,` или `.`; также `1,5`, `700`.
4. **Столбец** считается «дата/время» или «число», если **≥ 3** строк данных в нём успешно распознаны (сначала даты, затем числа в остальных столбцах).
5. Конвертируются **все** текстовые ячейки подходящего столбца, которые парсятся.
6. Пакеты по 200 строк, один load/save на файл.

Пустой `MERGE_XML_DATETIME_FORMATS` — базовый набор + дополнения по локали книги (ru: `DD/MM/YYYY`, `02.фев.1976`, …).

**Month-only:** шаблоны вида `FIRST_DAY.MMMM.YEAR`, `LAST_DAY.MMMM.NEXT_YEAR`, `01.ММММ.2027`
(день: литерал / `FIRST_DAY` / `LAST_DAY`; год: `YEAR` / `NEXT_YEAR` / `2027`).
Голый `MMMM` без дня и года не распознаёт «Январь» как дату.

## Копирование листов + xml: обрезка строк

| Ситуация | Поведение |
|----------|-----------|
| Явный `удаление_верхних_строк` (JSON с `sheet` или per_file без `sheet`) | Автообрезка **не выполняется**; только явное удаление N строк сверху |
| Явного параметра нет | Автообрезка в файле: строки до `Строка_Заголовков`, затем «промежуток» до `Начало_Строка` |

Работает в UNO (режим `По_API`) и в direct-фазе xml (`.ods` / `.xlsx` результата).

## Имена листов и новые вкладки

- После `переименовать_лист` / `копировать_лист` / `сводная_таблица` список `direct_result_sheet_names` перечитывается из файла.
- Новые листы → `direct_take_xml_created_sheets` → очередь UNO (`merge_pp_copy_sheet_register_pending`).
- При «На один лист» оформляются `Merge` и все добавленные вкладки (сводная и т.п.).

## 1. Чистый XML (файл: openpyxl / odfpy)

### Структурные (`_DIRECT_XML_FILE_STRUCTURAL_KEYS`)

| Ключ | Примечание |
|------|------------|
| `удалить_столбцы` | |
| `конкатенация_столбцов` | |
| `замена_значений` | |
| `заполнение_вниз` | |
| `заполнение_вниз_вычислить` | формулы в пустые ячейки |
| `сортировка` | |
| `переименовать_лист` | обновляет кэш имён |
| `переименовать_столбцы` | заголовки в файле |
| `переставить_столбцы` | порядок столбцов в файле |
| `копировать_лист` | новый лист → кэш + очередь UNO-пайплайна |
| `сводная_таблица` | статичный отчёт (не DataPilot); новый лист → кэш + очередь UNO |

**Только UNO (не XML-файл):** `добавить_столбец`, `столбец_по_лямбде`, `условный_столбец` — RANGE / Финал через LibreOffice API (формат + Validation).

**Не ключ `_DIRECT_XML_FILE_STRUCTURAL_KEYS`:** `объединить_листы_в_один` выполняется как **отдельная строка A** в xml-pipeline (`kind=merge_sheets`), аналогично ВПР_XML — не как B под `Постобработка_xml`. `header_row` в JSON — **1-based** на листах результата.

**Сводная:** при пустых `row_fields` строка «Итого» не пишется. Сортировка ключей устойчива к смеси float/str.

## 2. Гибрид (файл + UNO после показа книги)

### Очередь `_DIRECT_XML_UNO_PILOT_KEYS` → «Постобработка_xml+UNO»

| Ключ | Почему UNO |
|------|------------|
| `заголовок_плюс_высота` | OptimalHeight / оформление шапки |
| `перенос_и_авто_высота` | autofit строк |
| `авто_высота` / `авто_ширина` | OptimalHeight / OptimalWidth |
| `автофильтр` | DatabaseRanges + AutoFilter |

### Freeze (после показа окна)

| Ключ | Почему отдельно |
|------|-----------------|
| `закрепить_заголовок` | `freezeAtPosition` не работает при Hidden; также финальный шаг через `lm_set_freeze_defer_hook` |

### Формулы

| Ключ | Файл | После reopen |
|------|------|--------------|
| `применить_формулу` + `as_values` | запись формул | вычисление → значения |

### Автофильтр: один диапазон на лист

Встроенный `AF_*` (Автофильтр_результата) и `AF_PP_*` (шаг постобработки) не ставятся вместе — иначе стрелки на шапке и на первой строке данных.
