# Макрос `pick_source_file` — выбор файла-источника

**Файл:** `macro-lib/pick_source_file.py`  
**Точка входа:** `select_source_file`  
**Установка:** `./macro-lib/install.sh pick_source_file` (см. [INSTALL_GUIDE.md](INSTALL_GUIDE.md))

Макрос открывает стандартный диалог выбора файла и записывает **абсолютный путь** в строку параметра **«Файлы-Источники»** на листе `Параметры_Объединения*`.

---

## 1. Назначение

Ускоряет заполнение колонок B, C, D… в строке «Файлы-Источники»:

- не нужно вводить путь вручную;
- при добавлении столбца копируется оформление с соседнего («Значение N» в строке заголовков);
- начальная папка FilePicker подбирается по уже введённым путям.

Основной сбор данных выполняет [collect_workbooks](04_DATA_COLLECTION.md); этот макрос только **готовит параметры**.

---

## 2. Запуск

1. Откройте лист **`Параметры_Объединения`** (или лист группы с этим префиксом).
2. **Инструменты → Макросы → Выполнить макрос… → Python → pick_source_file → select_source_file**

**Рекомендуется:** кнопка формы в строке «Файлы-Источники» (событие «При нажатии» → этот макрос).

---

## 3. Поведение

### 3.1 Ячейка с путём не пустая (режим замены)

Условия:

- курсор в **строке «Файлы-Источники»**;
- активная ячейка в столбце **B или правее** (не A);
- в ячейке **уже есть текст** (путь или маска).

Тогда:

1. FilePicker открывается в каталоге **текущего значения** (имя файла — в поле имени, если это файл);
2. после выбора новый путь записывается **в ту же ячейку**;
3. фокус остаётся на этой ячейке.

Подходит для исправления пути к одному из источников (B, C, D…).

### 3.2 Ячейка пустая (режим добавления)

Если ячейка пустая **даже в строке «Файлы-Источники»**:

1. начальная папка — из **последнего непустого** значения в строке (B→C→…);
2. путь записывается в **первый свободный** столбец справа (B, затем C, D…);
3. при необходимости создаётся заголовок «Значение N» и копируется формат столбца.

Это прежнее поведение «добавить следующий файл».

### 3.3 Строка параметра не найдена

Макрос ищет строку с именем **Файлы-Источники** в колонке A:

- сначала в **текущей строке** (если курсор на ней);
- иначе сканирует лист сверху вниз.

Если строки нет — сообщение в консоль, запись не выполняется.

---

## 4. Формат записываемого пути

- В ячейку попадает **абсолютный** путь в нотации ОС (`C:\...` или `/home/...`).
- Макрос `collect_workbooks` при запуске может нормализовать пути (WSL, относительные пути) — см. раздел 5 в [04_DATA_COLLECTION.md](04_DATA_COLLECTION.md).

Поддерживаются маски в параметрах (`*.xlsx`); FilePicker выбирает **конкретный файл**, маску в ячейку вручную при необходимости.

---

## 5. Лист и столбцы

| Колонка | Содержимое |
|---------|------------|
| A | Имя параметра (`Файлы-Источники`) |
| B | Путь / маска для 1-го источника |
| C | 2-й источник |
| D | 3-й … |

Строка 0 (первая в Calc): заголовки «Параметр», «Значение 1», «Значение 2», …

Макрос работает на **активном листе**. Для книги с несколькими `Параметры_Объединения_*` активируйте нужный лист перед запуском.

---

## 6. Отличие от `param_wizard`

| | pick_source_file | param_wizard (`set_merge_param`) |
|--|------------------|----------------------------------|
| Только файлы | ✅ по одному пути в ячейку | ✅ все пути в одном поле, OK → B,C,D… |
| Кнопка в строке источников | ✅ | общий визард |
| Замена текущей ячейки | ✅ (ячейка не пустая) | ✅ (режим `files`, предзаполнение по столбцу) |
| Несколько файлов за раз | по одному вызову | ✅ список путей + Обзор / Очистить |
| Пресеты, постобработка, режим | ❌ | ✅ вкладка «Пресеты» |
| Объединение «Комментарий» при новых столбцах | ✅ | ✅ при OK в режиме `files` |

**Когда что использовать:** кнопка «Обзор» в строке — быстрая подстановка **одного** файла; визард — **пакетное** редактирование всех источников и остальных параметров.

---

## 7. Устранение неполадок

| Проблема | Решение |
|----------|---------|
| «Строка не найдена» | Добавьте в A имя `Файлы-Источники` (как в шаблоне тестов) |
| Путь не обновляется | Убедитесь, что ячейка **не пустая** для режима замены |
| Всегда новый столбец | Очистите ячейку или используйте режим замены (п. 3.1) |
| Нет диалога выбора файла | Права макросов, перезапуск Calc |
| Linux: путь с Windows-дисками | После сбора `collect_workbooks` нормализует пути |
