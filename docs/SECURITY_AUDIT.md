## Краткое резюме

Проект — локальный набор макросов LibreOffice/AlterOffice Calc (сбор книг, постобработка, почта, QR и др.). **Модель доверия:** книга параметров выполняется с правами пользователя ОС; согласия и гейты снижают случайный/чужой запуск, но не дают песочницы ОС.

| Уровень | Кол-во | Суть |
|---------|--------|------|
| Критический | 1 | «Предварительный_скрипт» — RCE **только** при совпадении env + зашифрованной глобальной |
| Высокий | 2 | Abs `file_ref` (H-2); остаток H-5 (статическая санация ≠ изоляция + UNO) |
| Средний | 5 | Почта; пароль инсталлятора; zip/XML DoS; MERGE_DEBUG; XML меню |
| Низкий | 3 | Конфиги в `~/.config`; temp; безопасные eval формул |
| Закрыто / существенно смягчено | 5 | C-2; H-6 LDAP/AD удалён; H-5 fail-open+builtins; H-1 доверенные корни; glob вне корней не разворачивается |

**Вывод:** для своих шаблонов риски управляемы. Для **чужих `.ods`/`.xltx`** без настроенных гейтов pre-shell/плагинов критический RCE блокируется; остаются B/C (санация) и незакрытый abs `file_ref`.

## Модель доверия

```
┌─────────────────────────────────────────────────────────────┐
│  Книга параметров (.ods / .xltx)                            │
│  ├── Файлы-Источники → проверка доверенных корней (strict)  │
│  ├── Постобработка B/C (AST-санация, fail-closed)           │
│  ├── Предварительный_скрипт → гейт env↔encrypted global     │
│  └── Финал: отправить_по_почте (локальный MUA)              │

┌─────────────────────────────────────────────────────────────┐
│  Права пользователя ОС                                      │
│  ├── ФС: только под разрешёнными корнями (если mode≠off)    │

│  └── subprocess (pre_shell при гейте; mailto/…)             │
└─────────────────────────────────────────────────────────────┘
```

## Находки по критичности

### Критический

#### C-3. «Предварительный_скрипт»

**Где:** `libre_macros_pre_shell_lib`, визард `mode: pre_shell`

**Гейт:** env `MERGE_ALLOW_PRE_SCRIPT` ↔ encrypted global `Merge_Allow_Pre_Scripts` (только сегмент «Глобальные_переменные»). Без совпадения сбор **прерывается до** confirm. `shell=False`, confirm UI, журнал `~/.config/libre-macros/pre_shell_consent/`.

**Рекомендации:** не класть значение допуска в шаблоны книг; ключ шифрования глобальных — вне общих каталогов.

#### C-3b. «функция_плагин»

**Гейт:** `allow_env`/`allow_global` или defaults `MERGE_ALLOW_PLUGINS` / `Merge_Allow_Plugins` (force encrypt). Ошибка — `show_collect_error`.

---

### Высокий

#### H-5. Eval/exec постобработки — санация есть, песочницы нет

**Смягчено (3.10.710):**
1. Fail-closed при недоступной санации / builtins.
2. Blocklist builtins синхронизирован с AST (`getattr`/`setattr`/…).

**Остаток:** статический фильтр; UNO/`doc`/`sheet` в namespace; возможны новые обходы эвристик.  
**Рекомендации:** `strict`-политика санации для недоверенных книг; whitelist плагинов; закрыть H-2.

#### H-2. Abs `file_ref` — не закрыто

`_merge_pp_resolve_script_path` принимает абсолютный путь. В sanitize_lib готовы `lm_sanitize_file_ref(allow_absolute=False)` / `lm_sanitize_load_file_function` — **не подключены** к resolve макроса.

#### H-1. «Файлы-Источники» — существенно смягчено (3.10.711)

**Гейт:** `libre_macros_source_roots_lib` + ручной cfg `libre_macros_source_roots_cfg.py`.

- Режим по умолчанию **`strict`**.
- Defaults: Linux `/home/{user}`, `/home/TN/{user}`; Windows `C:\Users\{user}`, `S:\{user}`, `H:\`; опционально каталог книги.
- Доп. корни: env `MERGE_ALLOWED_SOURCE_ROOTS`, глобальная `Merge_Allowed_Source_Roots` (не из книги).
- Режим `off`: env `MERGE_SOURCE_ROOTS_MODE` / глобальная `Merge_Source_Roots_Mode`.
- Glob без доверенного литерального префикса **не разворачивается** (нет обхода всего диска).
- Remote URL в strict по умолчанию запрещены.

Подробности и примеры — [19_SECURITY.md](19_SECURITY.md).

#### H-3. Утечка путей в «Сбор_книг_лог»

**Статус:** актуально; при `MERGE_DEBUG` temp могут не удаляться.

## Положительные меры (3.10.711)

1. AST-санация B/C + лямбды/фильтры; **fail-closed**; builtins ↔ AST.
2. Consent + предупреждение о плагинах.
3. Pre-shell: `shell=False`, confirm, гейт env↔encrypted global.
4. функция_плагин: гейт env↔encrypted global.
5. Источники: ReadOnly/discard; **доверенные корни** (cfg/env/global).
6. C-2 закрыт; AD/LDAP удалён; JSON-only в C.
7. defusedxml в ODF/openpyxl-пути (с оговорками); лимиты `MERGE_*_MAX_ROWS`.
8. Документы: [16_CODE_SANITIZE.md](16_CODE_SANITIZE.md), [19_SECURITY.md](19_SECURITY.md).

## Матрица угроз (кратко)

| Угроза | Итог |
|--------|------|
| Чужой шаблон + pre_shell без допуска | **Блокируется гейтом** |
| Чужой шаблон + pre_shell при настроенном допуске жертвы | Высокий / критический |
| Обход санации B/C | Высокий (снижен fail-closed) |
| Abs `file_ref` | Высокий — **открыт** |
| Путь/glob вне home/H: без доп. корней | **Блокируется** (strict) |
| Режим source roots `off` | Как раньше — полный trust к путям книги |
| Утечка путей через лог | Средний |

3. Предупреждение / ограничение `argv[0]` pre_shell (C-3).

## Заключение

К  **3.10.711** закрыты или сильно смягчены: сохранение источников (C-2), LDAP/AD (H-6), fail-open санации и рассинхрон builtins (H-5), произвольные пути источников (H-1). Pre-shell и плагины требуют явного допуска профиля. Главный незакрытый P0 по коду — **abs `file_ref` (H-2)**. Полное доверие к содержимому B/C внутри разрешённого API Calc сохраняется.
